# 待测试

使用临时工作区和测试素材。画布与插件场景分别在纯 Web 和 CLI 检查。

| 场景 | 操作与通过条件 |
| --- | --- |
| Android 与纯血鸿蒙包内预览 | 分别从 Android Studio 和 DevEco Studio 构建并安装调试包，确认鸿蒙 ArkTS 编译通过，启动时能加载包内 JS 和 CSS。断网打开，创建测试画布并检查点选、拖动、捏合、横竖屏切换和系统返回。检查画布与资产入口，并确认手机和平板上都没有 Agent 入口。 |
| 移动预览拉取模型列表 | 在 Android 和鸿蒙预览包配置未开放浏览器跨域的 HTTPS 测试渠道，分别检查 `/v1/models` 和 Gemini 列表。使用有效密钥应显示模型；无效密钥、上游限流和断网分别显示权限、限流或连接提示。渠道返回重定向时提示获取失败，改用最终服务地址后重新拉取。 |
| 移动预览生成和外部资源下载 | 配置未开放跨域的测试渠道，提交纯提示词生成，检查 Responses 流式输出、取消、图像和音频返回、视频提交及刷新后查询。刷新提示词库并验证插件索引和安装包可下载。使用当前预览的本地参考文件时，应在请求发出前提示暂不支持，WebView 桥接消息不应出现素材字节。 |
| 画布触控与手写笔 | 在手机和平板网页分别拖动节点和空白、立即捏合、先平移后加入第二指、长按框选和笔拖框选；节点释放时保存位置，中断时恢复原位。缩放中心跟随指间中点，移动或捏合取消长按，从屏幕边缘起手交给系统。桌面回归鼠标拖节点、框选、平移与滚轮。 |
| 文本节点拖动 | 在 45% 以上从已显示的正文起手，直接拖动短文本和长文本节点。双击进入长文本编辑后，用手指滚动正文时节点位置不变；桌面回归正文滚轮滚动。 |
| 桌面节点点选和拖动 | 在正常 Edge 和 Chrome 标签页点击文本节点正文，顶部菜单出现。拖动节点后松手并刷新，位置仍是移动后的坐标。双击正文进入编辑，选择文字时节点保持原位。 |
| 触屏节点工具缩放 | 将文本节点缩至 19% 和 10%，节点中部仍可点选并拖动。顶部菜单保持可读，端口仍可连线，右侧加号缩到最小外观后仍可点按。 |
| 触屏连线和创建下游 | 点击输出端口后点高亮输入端口完成连线；用手指或笔从端口直接拖到另一节点也能连线，拖到空白处可选择创建下游节点。换几个缩放级别检查端口热区，分别用拖出菜单和节点右侧「创建下游节点」创建节点，单次撤销同时移除节点和连线。 |
| 缩小视图与媒体释放 | 播放视频并打开节点输入面板，再将画布缩至 45% 以下。视频停止并显示封面或占位，文本折叠正文，输入面板收为「展开输入面板」按钮。还能打开输入面板，原草稿保留。放大后恢复正文和播放入口，视频等用户点播。 |
| 窄窗口与 Agent 入口 | 手机横竖屏和平板分屏时检查底栏、节点输入面板、抽屉开关和内部滚动；宽窗口显示可折叠侧栏。手机和平板网页隐藏 Agent 和 Agent配置，电脑 Web、CLI 与桌面版再检查 Agent 与 MCP。 |
| 局域网 Web 启动 | 手机或平板浏览器通过电脑的局域网 HTTP 地址打开开发服务，进入画布列表和项目。再回归 CLI 本地版的外部 Agent 连接。 |
| 局域网 Web 生成 | 通过局域网 HTTP 地址进入画布，提交或重试图片生成；在创作页新建对话并生成，检查记录可打开。画布视频提交后刷新，应按原任务继续查询。 |
| 局域网插件安装 | 通过局域网 HTTP 地址从市场安装单客户端文件插件，安装后可启用；修改包内容后应拒绝校验。安装多文件插件时应提示改用 HTTPS 或 localhost，并且不写入安装记录。 |
| 让 AI 写单文件插件 | CLI 本地版在「设置 → 插件」点「让 AI 帮我写插件」，把提示词发给 AI 并要求写一个底栏菜单插件：生成的 `client.js` 默认导出只有 `contributions`（及可选 `setup`、`css`），名称说明在 `plugin.json`；点「重新加载本地插件」后能启用，菜单项出现在画布底栏扩展菜单中。 |
| 从 GitHub 安装 Codex 插件 | dev 合并到 main 且 CLI 已发布到 npm 后，在没有本仓库的机器上运行 Codex 插件文档中的两条安装命令：插件显示已安装并启用；新建对话说「打开 Infinite Canvas」，能启动本地服务、打开画布并通过 MCP 读取画布。 |
| 创作页手机端输入框 | 浏览器切到手机宽度（约 375px）打开创作页：输入框底部的创作类型、模型、参数、提示词库、我的资产和发送按钮排在一行，模型名过长时省略显示；创作类型改为下拉选择，切换后对应模型和参数正常；桌面宽度仍显示原来的分段切换。 |
| CLI 重复启动 | 在一个终端运行 `serve --open` 后，另开终端用相同数据目录再次运行：提示已在运行并打开同一地址，不报目录被占用；第一个服务退出后再运行，能正常启动新服务。 |
| 渠道设置 | 新增渠道后选择默认分组，填写服务地址和 API Key，分别检查按名称添加模型以及拉取列表。打开已有渠道，确认分组和模型可管理。 |
| CLI 多开页面 | CLI 本地版同时打开 4 个以上工作台页面：每个页面都能正常加载；在一个页面保存作品，其他页面同步更新；外部 Agent 通过 MCP 能读取并操作当前聚焦的画布；停止并重新启动服务后，页面自动恢复连接；源码开发模式下热更新仍正常。 |
